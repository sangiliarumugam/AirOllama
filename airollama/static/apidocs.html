Ollama API Endpoint Compatibility (Port 11211)

AirOllama runs on http://localhost:11211 and is compatible with Ollama SDKs and OpenAI tools.

cURL Chat Completion

curl http://localhost:11211/api/chat -d '{ "model": "TinyLlama/TinyLlama-1.1B-Chat-v1.0", "messages": [{"role": "user", "content": "Explain gravity in 2 sentences"}], "stream": true }'

OpenAI Python SDK

from openai import OpenAI client = OpenAI(base_url="http://localhost:11211/v1", api_key="not-needed") response = client.chat.completions.create( model="TinyLlama/TinyLlama-1.1B-Chat-v1.0", messages=[{"role": "user", "content": "Hello!"}] ) print(response.choices[0].message.content)
